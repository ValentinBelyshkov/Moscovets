# Интеграция DWV в модуль КТ

## Обзор

Модуль КТ был полностью переработан с использованием библиотеки DWV (DICOM Web Viewer) - профессионального инструмента для просмотра и анализа DICOM медицинских изображений.

## Основные возможности

### Загрузка данных
- Загрузка ZIP архивов с DICOM файлами
- Прямая загрузка DICOM файлов (.dcm)
- Drag & Drop интерфейс
- Сохранение данных в localStorage для persistency
- Полностью клиентская обработка - нет отправки на сервер

### Инструменты просмотра DWV

#### Навигация
- **Scroll** (📜) - Прокрутка срезов
- **ZoomAndPan** (🔍) - Масштабирование и панорамирование

#### Настройка изображения
- **WindowLevel** (🔆) - Настройка окна/уровня (контраст/яркость)
- **Opacity** (👁️) - Настройка прозрачности

#### Измерения и аннотации
- **Draw** (✏️) - Рисование
  - **Ruler** (📏) - Линейка для измерений
  - **Ellipse** (⭕) - Эллипс
  - **Rectangle** (⬜) - Прямоугольник
  - **Protractor** - Транспортир для углов
- **Brush** (🖌️) - Кисть для рисования
- **Floodfill** (💧) - Заливка области
- **Livewire** (⚡) - Интеллектуальное выделение контуров

#### Фильтры
- **Filter** (✨) - Применение фильтров
  - **Threshold** - Пороговая обработка
  - **Sharpen** - Увеличение резкости
  - **Sobel** - Детекция границ
  - **Gaussian** - Гауссово размытие

### Информация DICOM

В панели метаданных отображается:
- Имя пациента (PatientName)
- Дата исследования (StudyDate)
- Модальность (Modality)
- Учреждение (InstitutionName)
- Толщина среза (SliceThickness)
- Другие метаданные

## Архитектура

### Компоненты

#### CTModule.js
Основной компонент модуля КТ:
- Управление загрузкой файлов
- Drag & Drop интерфейс
- Интеграция с localStorage
- Отображение DWV вьювера

#### DWVViewer.js
React компонент-обертка для DWV:
- Инициализация DWV App
- Управление инструментами
- Отображение прогресса загрузки
- Обработка ошибок

### Обработка файлов

Все операции выполняются на стороне клиента:
1. ZIP архив распаковывается с помощью JSZip
2. DICOM файлы извлекаются и сортируются
3. Файлы загружаются в DWV через File API
4. Данные сохраняются в localStorage как blob

### Безопасность

- Никакие медицинские данные не отправляются на сервер
- Все операции выполняются локально в браузере
- Данные сохраняются только в localStorage текущего устройства

## Установка и настройка

### Установка DWV
```bash
npm install dwv --save
```

### Workers
DWV использует Web Workers для обработки различных форматов JPEG. Workers скопированы в:
- `public/dwv-workers/` - для разработки
- `build/dwv-workers/` - для production

Список workers:
- jpeg2000.worker.min.js
- jpegbaseline.worker.min.js
- jpegloss.worker.min.js
- rle.worker.min.js
- labeling.worker.min.js
- resampling.worker.min.js

## Технические детали

### Зависимости
- `dwv` - основная библиотека DICOM viewer
- `jszip` - для распаковки ZIP архивов
- React 19+ для UI компонентов

### Совместимость
- Современные браузеры с поддержкой:
  - WebGL (для рендеринга)
  - Web Workers
  - File API
  - LocalStorage

### Ограничения
- Максимальный размер архива зависит от RAM устройства
- Рекомендуется использовать архивы до 500MB
- Для больших наборов данных рекомендуется разбивать на серии

## Использование

### Загрузка КТ
1. Перейдите в модуль КТ (/ct/:patientId)
2. Перетащите ZIP архив с DICOM или выберите файлы
3. Нажмите "Открыть в просмотрщике"
4. Используйте инструменты DWV для анализа

### Работа с инструментами
1. Выберите инструмент на панели
2. Применяйте к изображению:
   - Левая кнопка мыши - основное действие
   - Правая кнопка мыши - дополнительные опции
   - Колесо мыши - прокрутка/масштаб

### Управление окном/уровнем
- Выберите инструмент "WindowLevel"
- Перетаскивайте мышь для настройки:
  - Влево/вправо - изменение окна (контраст)
  - Вверх/вниз - изменение уровня (яркость)

## Расширение функциональности

### Добавление новых инструментов
В DWVViewer.js добавьте инструмент в конфигурацию:
```javascript
app.init({
  tools: {
    YourTool: {
      // опции инструмента
    }
  }
});
```

### Добавление новых фильтров
Аналогично инструментам, используйте Filter с нужными опциями.

## Устранение неполадок

### Проблемы с загрузкой
- Проверьте формат файлов (должны быть .dcm или .dicom)
- Убедитесь что ZIP архив не поврежден
- Проверьте консоль браузера на ошибки

### Проблемы с отображением
- Убедитесь что WebGL включен в браузере
- Проверьте поддержку Web Workers
- Очистите localStorage если данные повреждены

### Производительность
- Для больших серий используйте субсэмплинг
- Закрывайте неиспользуемые вкладки браузера
- Используйте современный браузер с хорошей поддержкой WebGL
