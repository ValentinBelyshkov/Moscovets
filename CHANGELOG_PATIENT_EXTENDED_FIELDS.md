### Технические детали

**Типы данных**
- String: все текстовые поля (адрес, контакты)
- Float: кефалометрические измерения в миллиметрах
- Boolean: флаги (симметричность, губы сомкнуты, и т.д.)
- Enum: категориальные данные (пол, образование, тип профиля, и т.д.)
- Date: дата рождения
- DateTime: временные метки

**Особенности реализации**
- Все новые поля опциональные (nullable=True)
- Enum значения хранятся на английском языке
- Frontend отображает русские labels
- Поддержка частичного обновления (можно обновить только нужные поля)
- Обратная совместимость с существующими данными
- SQLAlchemy ORM для работы с БД
- Pydantic v2 для валидации

**База данных**
- SQLite для локальной разработки
- PostgreSQL для production
- Автоматическое создание индексов
- Уникальный индекс для medical_card_number
- Временные метки с автообновлением

### API Endpoints

Все существующие endpoints поддерживают новые поля:

- `GET /api/v1/patients/` - получить список пациентов (с новыми полями)
- `POST /api/v1/patients/` - создать пациента (с новыми полями)
- `GET /api/v1/patients/{id}` - получить пациента по ID (с новыми полями)
- `PUT /api/v1/patients/{id}` - обновить пациента (поддержка частичного обновления)
- `DELETE /api/v1/patients/{id}` - удалить пациента (без изменений)

